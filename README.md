# mydocker

Building a minimal container runtime from scratch to understand how Docker works under the hood.

## Progress
- [x] Stage 1: Hostname isolation (UTS namespace)
- [x] Stage 2: Process isolation (PID namespace)
- [ ] Stage 3: Filesystem isolation (chroot + mount namespace)
- [ ] Stage 4: Resource limits (cgroups)
- [ ] Stage 5: Networking
